# Buzdolabı Lambası Komisyonu

Resmi soru: Kapı kapanınca lamba sönüyor mu?

Resmi cevap: Komisyon toplandı, çay geldi, lamba ifade vermedi, dosya raflandı, raflar da dolaptan çıktı.

Bu depo, insanlığın en eski fizik problemini çözmek için kurulmuş ciddi bir kurumdur. Ciddiyeti, çay bardağının altlığı kadar incedir ama evrak kadar kalındır.

## Ne yapar

`python lamba_sorusturma.py` çalıştırınca:

- kapı açılır, lamba yanar, yoğurt şahitlik eder
- kapı kapanır, sensör “görmedim” der
- komisyon üç ayrı tutanak yazar: söndü / sönmedi / çay molası
- sonunda bir karar basar. Karar değişebilir. Dolap değişmez.

Argüman da var:

```bash
python lamba_sorusturma.py --kapi acik
python lamba_sorusturma.py --kapi kapali --tur 5
```

## Kuruluş gerekçesi

Bir gece biri süt almak için dolabı açtı. Lamba yandı. Kapı kapandı. Lamba ne yaptı? Bilinmiyor. Bu bilinmezlik ülke meselesidir. Ülke meselesi olunca komisyon kurulur. Komisyon kurulunca README yazılır.

## Mimari

Tek dosya. Tek lamba. Sıfır mikroservis. Sıfır Kubernetes. Kubernetes dolaba sığmaz, yoğurt küser.

## Lisans

Lambanız sönerse suç bizde değil. Lambanız sönmezse de suç bizde değil. Suç, kapıyı kapatan kişidedir; o kişi genelde sizsiniz.
